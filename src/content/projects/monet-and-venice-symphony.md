## Problem

The exhibition catalog prints one web address for the symphony. It has to keep working for decades, on any phone, with no server to maintain.

## What I built

The permanent web edition of the 36‑minute, six-movement symphony: one file of plain HTML, CSS, and JavaScript, stored on Arweave under a web address held through 2075.
